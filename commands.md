# Git Commands I Used

## git clone
I used this to download the repository to my computer.

## git status
I used this to check which branch I was on and whether there were any changes.

## git add
I used this to add the files I wanted to include in a commit.

## git commit
I used this to save my changes with a commit message.

## git log --oneline
I used this to see my previous commits and get the commit hash.

## git branch
I used this to create my new branch.

## git switch
I used this to move between the main branch and my Rahul branch.

## git merge
I used this to merge my Rahul branch back into main.

## git reset
I used this to undo the latest commit as required in the task.

## git push
I used this to upload my local changes to my GitHub repository.
